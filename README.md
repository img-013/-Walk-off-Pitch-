# 再见一掷 · Walk-off Pitch

**骰子落定，总有人先离席。**

一款以骰子对决与永久规则构筑为核心的 Roguelike 原型。沿雾港的分岔路线前行，挑战赌徒、拜访行商，在酒馆整备。每回合三次掷骰，中间锁定想保留的结果；最终点数差化为伤害。收集自动触发的规则，让奇偶、对子、早锁、险境和逆点成为你的胜算。

当前版本 **0.10.0**：33种机制敌人、三章46步／26场战斗、回合意图、限锁与延迟反制、税契与主动加注、三位阶段首领。保留白鲸序章、几何切面美术与80张规则牌。

规则内容仍为 **0.8.0 卡池**：80 张全部可用规则，八个核心、八个专属流派；开局选择核心和方向，八次免费奖励。新增三章路线，保留图鉴、预览和节点存档。全部数值仍处于原型验证阶段。美术实现使用原创SVG切面与CSS动画，没有复制参考图水印素材。

## 开始游玩

可直接[在线游玩](https://img-013.github.io/-Walk-off-Pitch-/)，也可下载仓库并用浏览器打开根目录 [index.html](index.html)。下载版是自包含单文件，无需安装、网络或服务器。

1. 启程观看序章，在飞散的行李中选择主戒律。可跳过过场，随后选择方向和初始规则卡。
2. 每回合掷骰三次；第一、二掷后可点击己方骰子锁定。
3. 第三掷后阅读结算预览，再揭晓胜负。
4. 获得的规则自动生效；最多 5 张被动 + 1 张核心，满位可替换。

浏览器允许本地存储时，在已完成地图节点自动存档。v0.5、v0.6、v0.8 与 v0.10 使用不同存档键，旧存档不会被覆盖，也不会自动转换。

## 开发

需要 Node.js 22 或更新版本，没有第三方运行依赖，也不需要 `npm install`。

```sh
node scripts/check.cjs
node scripts/simulate-enemies.cjs
```

安装了 npm 的环境也可以运行 `npm run check` 和 `npm run simulate`。构建会把 `src/`、卡牌与敌人数据库嵌入 `index.html`，同时生成 CSV 与卡牌文档。

```text
data/       卡牌、敌人、字段规范
src/        界面、样式、纯结算引擎
scripts/    校验、构建、自动对战
tests/      规则测试与交互流程测试
docs/       研究、设计、卡牌及平衡基线
prototypes/ 历史 v0.5 原型
```

CI 在推送 main 和提交 PR 时校验数据、重新构建、运行测试，并检查生成文件是否同步。贡献说明见 [CONTRIBUTING](CONTRIBUTING.md)。

## 当前限制

- 80张卡、33敌人已实现，仍是平衡测试版；终局首领对不同流派差距明显。模拟不等于人类胜率或完整远征通关率。
- 本轮没有扩写40个独立事件，目前是命运借据事件与三章敌人系统。
- 测试包含纯逻辑和 DOM 替身流程。另在真实浏览器检查了开场前三幕、桌面与390像素窄屏选卡布局；完整战斗流程及手机实机帧率尚未完成视觉验收。
- 自动模拟测获得构筑、独立对战与合法构筑抽样，不能作为真实通关率；包含条件、策略及超时说明。
- 本版不含完整回放播放器、战斗中断点续玩、手柄支持、多语言或音量设置。
- 项目尚未指定开源许可证；公开仓库不代表授予任意再分发或商业使用许可。
