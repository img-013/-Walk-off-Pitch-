# 再见一掷 · Godot 原生迁移版 0.1

本工程使用 Godot 4.6，3D 酒馆场景 + 原生 2D 页面；不嵌入网页，也不依赖 Node 服务运行。

本机可直接打开 `C:/Users/brz18/Documents/watch-off-throw/project.godot`，按 **F5**。仓库的 `godot/` 是同一工程的提交副本。网页版继续保留，GitHub Pages 目前仍然运行网页版。

| `scenes/tavern.tscn` | 用户新酒馆 `Cabaret`、镜头、骰子位置、环境光 |

| `scenes/ui/*.tscn` | 各个页面独立打开即可查看和编辑 2D 节点 |
| `scenes/cabaret_filter.tscn` | 像素尺寸、黑白比例、灰阶、曝光和暗角 |
| `scenes/cabaret_audio.tscn` | 主音乐与四种反馈音效，独立播放器与音量 |
| `scenes/dice.tscn` | `DiceBody/Mesh` 是空白骰体，`DiceBody/Face0`～`Face5` 是独立贴面；替换骰体模型不需要重做规则 |

场景已保存为普通 `.tscn`，无需运行生成脚本。独立 UI 场景默认可见，主场景默认显示首页。地图、六个规则位和锁骰按钮均已保存为节点。

主界面按 1280 × 800 设计，按窗口比例缩放。首页「设置」可切全屏、改变掷骰动画速度。

## 已迁移的玩法

- 新游戏、继续远征，8 个主戒律 + 无戒律选项；有戒律 5 个辅助规则位，无戒律 6 个。
- 80 张卡牌的数据、计分与联动处理；图鉴、奖励选择、满位替换、互斥检查。
- 三章 46 步分岔地图；33 个敌人的机制、Boss 分阶段、敌人意图和税金／加注等主动选择。
- 每回合三次投掷、锁骰、差值伤害、护盾、伤害／金币／治疗上限、下回合储存。
- 原版固定成长节点发卡；商店最多购买两张、付费刷新一次；酒馆恢复和永久校准骰面；已实现的许愿井事件。
- 首局「命运本身」引导及头像；后续不重复引导。
- 原生自动存档，包含随机数状态、骰面、锁骰和商店货架；动画期间禁止重复操作。

`scripts/rules_engine.gd` 是无副作用结算器，`run_state.gd` 管理远征状态、抽签和存档，`enemy_mechanics.gd` 管理敌人意图，`main.gd` 绑定页面，`die.gd` 只负责视觉。

## 骰面与动画

每次先由 `RunState` 抽取 0～5 的**物理面索引**，再从六面数组读出数值。重复数值的骰子也保留准确的面索引。`Dice.roll_to()` 收到索引后旋转，动画不调用玩法随机数。

六个面相对关系为 1↔6、2↔5、3↔4。骨质本体使用受光材质，贴面略偏离表面，使用最近邻采样。临时改点只更新当次显示，酒馆校准才改变存档内的永久六面数组。

`face_symbols` 的 `fire` / `critical` 是可编辑的视觉接口；尚未新增这些符号的战斗效果，避免把额外玩法悄悄混入现有规则。数值仍由 `face_values` 指定。

## 当前边界

- 酒馆采用用户最新提供的哥特歌舞厅 GLB，保留其桌椅和布景；骰体采用 CC0 模型的空白化版本。33 名敌人有机制和头像，独立 3D 怪物尚未制作。
- 遗物与敌人 2D 图集沿用用户此前提供的素材，后续可逐项换成新的复古中世纪风格。
- 原仓库没有 40 个已实现事件，只有许愿井；本次如实迁移该事件，没有把规划数量标成完成。
- 已接入用户的主背景音乐及原创合成音效；骰子采用逻辑先确定结果的可控动画。
- 原生存档位于 `user://expedition-godot-v1.json`，与网页存档不互通；不会覆盖浏览器存档。Godot 使用自身随机数生成器，同一存档可续接，但不承诺与网页相同种子产生相同路线。
