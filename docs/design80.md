## 核心先于构筑

开局在八张核心中选一张，再选择八种构筑方向之一。首张辅助三选一之后启程。核心包括反向赌局、单骰决胜、十二点约、偶数法庭、组合裁决、封骰契约、末掷镜像、熔金赌约。

最高骰核心不再废掉计分辅助：每2优势兑换1额外伤害或护盾，上限3；不改变最高骰胜负。最高骰相同时继续比总和。其他核心也保留优势阶段。兼容表示存在有效用法，不表示所有组合都强，或无须搭配条件牌。

## 获得机会与牌位

- 开局一次，前七个节点各一次免费三选一，共8次；首领胜利结束。此数量以成功到达各节点为前提。
- 三选一尽量提供方向相关、通用／桥接、探索各一张；去除已拥有卡，组内不重复。满位替换免费，取消替换返回相同三张，不重抽。
- 商店最多购买两张，可付5金币刷新一次，离店仍有节点免费奖励。事件生命换牌是额外机会。
- 构筑方向与辅助牌顺序可以在地图收藏中调整。自动模拟采用固定方向，不模拟转型收益。
- 每张牌都占槽，经济牌也有战斗机会成本。购买消费回流本身的价格也计入消费，因为装备确认后扣款；取消不扣款。卸下消费回流清除未兑现银行及零头。

## 单一结算与资源边界

物理掷骰 → 固定面替换（各牌读取物理结果，不互相串改）→ 末掷镜像 → 翻面锚 → 末掷校准 → 同律修整 → 可见骰面组合 → 优势及转换 → 胜负 → 伤害 → 产金／治疗／储存 → 一次性状态提交。

预览与正式结算共用纯函数。掷骰只采样一次，动画不抽随机数。临时改面保持到当前回合结束；固定面替换只在装备期间生效，不通过反复装备永久刷面。三次投掷不变，第三掷全锁也算一次投掷动作。

| 资源 | 上限与消耗 |
|---|---|
| 回合产金 | 每场所有回合牌合计12；部分牌还有更小单卡上限；熔金也消耗该额度 |
| 回合治疗 | 每场6；不得复活；战后与入场治疗独立 |
| 下回合优势／护盾 | 各3，当回合后统一储存，下回合消耗，战斗间清空 |
| 胜出额外伤害 | 所有来源合计6，不含基础差值 |
| 消费银行 | 下场首回合最多3优势，使用后清空，零头可留到再次消费 |
| 借贷 | 每场一次，下场首回合2优势惩罚，不能靠护盾消掉支付生命 |

## 量化口径与未解决问题

详见 [实验报告](balance80.md) 与 [核心适配证据](compatibility80.json)。P_build 的强度门槛是对普通敌人三种子至少两胜，并非八层通关；10万样本只覆盖奖励选择。D_effective 为经过强度门槛的机制签名，不将不同卡名的排列都算成新玩法。E 为合法构筑抽样估计，不枚举超过一亿组合。

一次先验启发式只追同流派导致骰面流角色单一；最终选择策略明确加入“至少三张相关牌后补齐功能角色”。该策略是模拟玩家合理选择的假设，UI仍由玩家自己选，不代替玩家。

仍需真人试玩检查：新手是否理解改面顺序、护盾构筑战斗偏长、八核心实际通关强弱、UI滚动和真实动画表现。自动测试中40回合未结束记超时，不掩盖为胜利。未完成这些验证前不宣称商业版本平衡完成。
