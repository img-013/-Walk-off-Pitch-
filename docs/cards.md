# 卡牌数据库 · 0.6.0

此文件由 data/cards.json 生成，请修改 JSON 后运行 npm run build。CSV 适合用 Excel 浏览，回写请以 JSON 为准。

24 张已实现、8 张设计稿。所有数值为待验证原型值。每局最多 5 张被动 + 1 张核心；同名唯一，核心互斥。

“优势”在正常模式加分，在反向模式减分（最低 0）。其他条件均检查原始骰面，除非卡面明确说明。
