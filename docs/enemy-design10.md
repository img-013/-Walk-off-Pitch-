# v0.10 敌人系统：实现与验收边界

本轮以用户提供的敌人规划为设计输入，未把其中示例胜率或机制占比当作行业事实。实现的是可玩的敌人系统与三章路线，不是仅增加名字、血量的数据库。80张卡牌的独立效果保持兼容。

## 规模与分工

N = A + V + E + B = 13 + 8 + 9 + 3 = 33。第一章11、第二章12、第三章10；21普通、9精英、3首领。完整清单见 [敌人数据库](enemies10.md)，卡牌关联仍以 [cards.json](../data/cards.json) 为准。

主要分支数量：数值7、干扰7、牌型5、节奏5、资源3、反制3、风险2、战场1。按33个整数名额近似20/20/15/15/10/10/5/5百分比，分别为21.2/21.2/15.2/15.2/9.1/9.1/6.1/3.0%。不是给每个敌人叠加八种机制。

基础行为为保留4–6，反向赌局改为保留1–3。机制模块改变锁定权限、护盾、伤害、得分或交易；章节通过遭遇池、基础生命、精英占比和机制复杂度成长。普通海鸥保留双骰新手定位，其他敌人使用三骰。

普通第一章原型只有一个主机制；变体和精英开始组合，首领半血进入第二阶段。阶段从下一回合开始生效，不在投骰后突然改变已发布意图。组合不是独立职业分类，同一基础机制可以在不同节奏下制造不同取舍。

## 公平性与卡牌关联

| 考题 | 关联卡与取舍 | 至少两种应对 |
|---|---|---|
| 指定一骰限锁 | R015早定之约仍可作用另外两骰；R046守序锚点须留意下一回合指定位置 | 锁住另外两骰；把受限骰用于R017放手一搏／R069破釜重投的重投收益 |
| 重复牌型护盾 | R075组合裁决允许对子／顺子／三同切换；R013步步相连不被禁用 | 切换牌型；维持强势主构筑，用优势穿过2点护盾 |
| 倒计时爆发 | 爆发只在敌方赢时附加，护盾在附加后抵消伤害 | 提前击败；在已预告的第4轮选择保守点数及护盾 |
| 税契 | 拒税零金币也可进行；R065消费回流记录实际付费但仅储存给下场 | 支付6金币解约；拒绝并承担+1败北伤害，胜后额外8金币 |
| 延迟规则审查 | 根据此前辅助牌实际触发次数选择流派；每张得分收益只减1，最低0；不禁主戒律 | 下一回合改变组合以触发另一类收益；继续主流派并承受有限削弱 |
| 自愿加注 | 双方最终伤害翻倍，获胜再得2金币；不属于R078的卡牌产金 | 投骰前接受高风险；忽略按钮维持原赌局 |
| 潮汐 | 奇数回合双方1–2点、偶数回合双方5–6点各给1优势；R007仍是低者胜，R008额外优势转伤害／护盾 | 随潮汐调整保留骰；坚持当前主戒律与强构筑 |
| 连胜追击 | 玩家连胜增加敌人胜出时伤害，最多3；败北清零 | 连续压制不给敌方赢面；用护盾承受一次败北重置，不能保证主动放输合算 |

规则审查统计学校（school），不按某张牌直接禁用。反制只影响得分型收益，经济、治疗和主戒律继续运行。最高骰模式的潮汐优势遵守原有优势转伤害／护盾规则。

## 地图、债务、奖励与存档

三章步数15+16+15=46，战斗8+10+8=26（含各章3精英、1首领）。当前章节单独显示，分支可选择不同敌人。分配时排除上一战主分支，并在首领前排除该首领的主分支。固定种子与遭遇表一并保存，刷新不能重抽敌人。

第三章远节点显示未知；再前一层显示类型／危险／机制分支；可进入层显示身份及完整描述。进入前可在地图情报按钮中读到机制，再决定路径。第三章3列逐渐收束到2列、最后1个首领。

本轮增加一类命运借据事件：借钱加债、偿债或免费恢复。债务至少2时，第三章每第三回合敌方胜出伤害+1，写入意图；不改变血量，也不随债务无限叠加。**本仓库此前只有一类事件，本轮没有声称已完成40个事件的独立内容库。**

沿用8次免费规则选择的构筑预算：开局 + 全局层0/1/6/13/20/29/40（层从0开始）。所有祭坛均包含在内。其他节点不额外无限发牌或发放弃奖励；商店购买仍可补充。普通战胜后恢复3生命，精英恢复5，章节首领后完全恢复，帮助26战远征维持续航。这些都是原型参数，仍须完整远征平衡测试。

v0.10另存 `walkoffpitch-v10`，不读取或删除v0.8/v0.9存档。旧单章HTML仍可继续旧存档。60回合仍未分胜负则封盘，本次远征以僵局结束，不发胜利奖励，可导出诊断；不能利用僵局通关首领。

## 威胁与模拟

T = .20H + .30A + .20C + .20S + .10R，所有分量限制在[0,1]。H=生命/60；A为骰数基础威胁与伤害机制数量的有限加权；C为受限骰比例；S为构筑限制机制数量的有限加权；R取可选资源风险标记。原始分量随数据导出，可以审查。它是设计评分，未用模拟胜率倒推或冒充客观难度。

详见 [33×8实测矩阵](enemy-balance10.md) 与 [原始结果](enemy-balance10.json)。16,896场独立完整构筑对战，含全部八主戒律；88场达到60回合上限。普通敌人各流派汇总没有低于20%的格子，但聚合结果不能证明每个核心搭配都公平。例如终局首领的改骰流仅12.5%，险境流96.9%，仍有明显平衡差距，下一步应分别比较合理主戒律搭配与投骰策略，不能据此宣称已经平衡。

1000地图种子、25000组抽样相邻战斗，R=0，33种敌人全部出现。单元测试额外检查这1000种子所有分支的相邻主机制，不能保证玩家主观体验始终不同。

机制可理解性与玩家是否主动调整策略必须真人测试；自动测试只证明特定输入、预告、选择、结算和存档路径一致。完整46步的真实通关率尚未得出。

## 文件与复现

- `scripts/enemies10.cjs`：33敌人作者数据，构建时导出 `data/enemies.json` 与 `docs/enemies10.md`。
- `src/enemy-system.js`：纯机制、意图、战斗记忆、威胁评分；`src/engine.js`共享真实结算。
- `src/campaign.js`：章节图与可复现遭遇表；`src/enemy-ui.js`：情报、交易、敌人图鉴。
- `node scripts/check.cjs`：数据、构建、全部自动测试。
- `node scripts/simulate-enemies.cjs`：重新生成敌人矩阵及遭遇指标。

v0.8平衡报告为当时的历史实验，不把旧报告数字用于新敌人和三章通关率。美术替换素材仍等待用户指定，本轮不擅自把UI边框当第三幕插画。
