# v0.12 档案拼贴美术接入

## 交付范围

直接使用四张用户原图：开始界面、戒律选择、战斗底图、敌人图集。原图保持完整，CSS按照原始坐标裁切卡框、四个按钮和立绘，作为独立可交互元素。开始菜单的开始游戏、查看规则、设置分别对应真实操作。白鲸漫画与上岸过场不再进入流程，也不再嵌入旧白鲸素材。

战斗图六个卡位对应五张辅助规则和一条主戒律。黑色区域包含阶段、敌人意图、结算预览和滚动战斗记录。底部按钮依次为敌人信息、投掷骰子、结束回合、规则查看；结束回合仍在第三掷后结算，不改变战斗规则。

八件原图遗物分别绑定：沙漏／单骰决胜、星仪／十二点约、天平／偶数法庭、拼图／组合裁决、骰子／反向赌局、圣杯／熔金赌约、魔镜／末掷镜像、卷轴／封骰契约。悬停或键盘聚焦预览，点击选中放大高亮，确认后装备。图中烘焙的标签保留原样；真实规则名称和效果显示于下方说明面板。

33个敌人使用33个独立图集区域。显示名称与新立绘匹配，ENEMY_DISPLAY12、ENEMY_ART12记录ID对应；机制与数值仍由原敌人数据库控制。原图第一排重复审判官有两幅近似图，本版使用精英列，另一列作为备用；没有将重复图计为新增敌人。

## 新地图生成提示

使用内置图像生成工具，不使用TapNow连接器。提示词：纵向2:3生产级游戏地图背景；古典雕塑残片、哥特赌场建筑、阶梯和骰子集中于左右边缘与底部，中间65%保留浅色空白以承载可交互路线。冷灰白旧档案纸、细密不完整蚀刻排线、复印颗粒、丝印网点、纸纤维、粗黑干刷。约85%黑白灰、12%高饱和群青圆形与色块、3%红色手绘路径。非对称拼贴、技术制图线、十字、套印错位。无文字、无按钮、无路线节点、无自然写实背景、无光滑3D、无青绿和金色。

## 验证与限制

本次按用户要求只运行素材完整性脚本及24项界面流程检查，未重跑大规模对战与平衡模拟。浏览器确认开始菜单、遗物选择、卡牌、地图、头像、敌人信息、投掷、结束回合、规则查看，以及一回合的实时记录；未进行完整远征巡检。五张PNG均存在并嵌入，八个裁切坐标未越界，33个敌人均有独立头像绑定。

沿用v0.11存档。旧存档可继续，新开局使用当前美术及名称。构图按原图比例缩放并留边，避免拉伸；窄竖屏下推荐横屏以阅读细小文字。原图中的英文LAST ROLL按用户原图保留，项目代码名称仍为Walk-off Pitch。
