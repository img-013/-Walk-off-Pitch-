# v0.9 美术、开场与引导

## 视觉方向

用户本轮描述优先于旧版墨绿旧金基线：深青绿、墨蓝、灰绿色构成立体主义切面；暗红／橙色只用于白鲸眼睛、伤害和少量窗口。几何面以明确色块表达体积，不使用柔和曲线塑形。UI参考用户提供图片的象牙白描边、方形图标、分段血条及阶梯边角，重新用CSS与SVG制作，没有使用原图像素或水印素材。

场景、海浪、白鲸、船体、箱子、赌城、人物与海鸥均为项目原创SVG。它们是可动画的二维矢量切面，不是假称已完成的三维模型。当前四幕是带运镜、撞击晃动和交互选卡的分镜演出，不是预渲染电影。

## 卡牌与输入反馈

- 选卡入场依次上移、回正；悬停轻微倾斜并抬升，按下收缩。
- 卡牌触发时弹起、左右小幅回弹；伤害造成短促场景震动；结算条目逐项出现。
- 战斗卡面保留短摘要，点击或键盘Enter／空格打开完整效果。
- 顶栏动效按钮可切换1倍／2.5倍速度；系统prefers-reduced-motion会关闭晃动、倾斜、弹跳和结算等待。
- 动画不读取或修改游戏随机数，不改变卡牌效果、骰面与结算。
- 对白遮罩期间禁止掷骰和结算，键盘焦点限制在对白按钮；跳过过场仍必须选择主戒律。
