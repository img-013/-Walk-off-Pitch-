# v0.11 美术与交互实现

## 体验

首页适配单屏。页头固定，章节说明停留左侧，路线独立纵向滚动。第一、二章采用2～4条分路并汇合，第三章逐渐收束。保留46步、26战斗及8次免费选牌预算；非战斗分支可选择事件、酒馆或商店。移除侧栏敌人预览，保留节点提示。

黑屏点击后只显示漫画左上格，再点击显示完整双格；随后进入箱中遗物选择。鼠标悬停或键盘聚焦查看规则，点击放大高亮，确认后装备。触屏使用点击预览。神秘人对白只出现在该浏览器的第一局；关闭本地存储时仅当前页面记忆。预览模式不写用户存档。

战斗框上方五格为辅助卡，右上容器显示当前主戒律，点击可看全文。原图骰子实际位于右上角，沿用该位置；核心图标不改变规则效果。结算明细包含历史记录和诊断导出；规则书内可重新启程、检视骰面。新地图使用v0.11独立存档，v0.10存档保留、不转换。
