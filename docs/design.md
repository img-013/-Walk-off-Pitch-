# 再见一掷 · 玩法设计 v0.6

## 已确定的核心

分岔地图决定风险和补给；每回合三次掷骰、其中两次调整锁定；双方最后一次点数确定后按规则比较，差值化为伤害；反复交锋直至一方生命归零。规则牌常驻且自动触发，不引入抽牌、手牌、能量或主动出牌窗口。

美术保留墨绿、旧金、象牙白的雾港赌桌。标题统一为「再见一掷 / Walk-off Pitch」。文案基调是下注般的抉择与告别，不扩展成真实金钱赌博系统。

## 一回合的可执行约定

1. 首次掷出三枚玩家骰子和敌人骰子。每枚基础六面为 1–6；酒馆可把第一枚骰子的 1 面升级为 3 面。
2. 第一掷后可以反复改变锁定；点击不消耗投掷次数。连续早锁资格只有此时建立，之后解除就丢失。
3. 第二掷仅重掷未锁定骰子。敌方按公开策略保留 4–6；逆点模式保留 1–3。
4. 第三掷仍照上述规则执行。即便全锁，也要推进到第三掷；对手仍可能重掷。第三掷结束不能再改锁定。
5. 展示完整结算预览。确认后结算一次，动画过程中不能再掷骰、锁骰或结算。
6. 未结束战斗则双方回合状态清零。持续规则继续存在，战斗内成长和金币计数保留；下一场战斗清零。

前三掷不是“三局两胜”，也不是整个战斗只能三回合。平局默认无伤，卡牌可以改变平局处理。当前未加游戏内硬回合上限；模拟的 40 回合上限只是测试保护。

## 结算次序和语义

| 阶段 | 行为 | 不允许做的事 |
|---|---|---|
| 原始骰面 | 保存玩家与敌方最终可见面值 | 为了动画重采样随机数 |
| 敌方复制 | 镜面赌徒在计分副本中复制玩家最高骰 | 永久改变敌骰面或下一回合骰值 |
| 基础分 | 通常求和；单骰模式先比最高，相同改比原始总和 | 两种基础比较同时混算 |
| 计分 | 检查原始组合、连续锁定、末掷数量等，逐项应用优势 | 让加分改变“原始奇偶”条件 |
| 敌方加成 | Boss 半血偶数共鸣；同样按模式解释优势 | 在单骰模式偷偷恢复已停用的加分 |
| 胜负 | 高者胜或低者胜；相同则处理庄家通吃 | 同时存在两个核心胜负模式 |
| 伤害 | 差值；获胜额外伤害；失败免差值 → 风险附加 → 减伤 | 免伤自动抵消所有风险成本 |
| 经济 | 条件金币按场封顶；战斗击败奖励一次 | 预览或动画重播发放奖励 |

“优势”不是一个额外的可消耗资源，仅用于明确加减方向：通常加点，逆点减点，最低为 0。数据库 `params` 给出数值，引擎给出执行语义；卡文必须跟着两者同步。

单骰核心跳过所有计分加成，包括己方玻璃誓约的优势和 Boss 共鸣。玻璃誓约的失败附加伤害仍属于伤害阶段，仍会触发，因此把它带进单骰构筑是明确的负面搭配。规则栏标记停用的计分牌，图鉴记录取舍。

## 构筑槽与获得

- 5 个被动位、1 个核心位。同名不叠加。
- 核心只包括 R007 反向赌局、R008 单骰决胜；R006 庄家通吃是稀有被动，可以搭配任一核心。
- 满位时，新牌替换同类位置中的一张，或取消。没有无限背包或战斗内换装。
- 普通战/精英胜利、祭坛、事件可提供三选一；商店按价格购买。奖励可放弃获得 8 金币。
- 奖励池只含已实现、未持有牌。存在与持有牌有协同的候选时，优先给一个关联选项；再给一个普通选项，剩余按稀有度权重随机抽取，选项不重复。
- 概率来自带种子的随机序列；UI 音效与动画不消耗该序列。没有暗中改骰或保底胜利。

## 七组值得试玩的技能关联

| 方向 | 关键卡 | 玩家决策改变 | 机会成本与对策 |
|---|---|---|---|
| 奇数经济 | R001 奇数信徒 + R010 拒绝对称 | 可能保留 3、5，放弃更大的偶数 | 全奇才发金币，且每场封顶；经济卡少一个直接战斗位 |
| 对子爆发 | R002 双生骰 + R014 三重奏 + R024 双响余威 | 保留一对，追第三枚，不总保留最高单骰 | 三同号有失败风险；对子与三同号各只触发一次 |
| 顺子 | R003 三人成行 + R013 步步相连 | 保留缺口两侧，追中间点数 | 与对子互斥；低顺子可能不敌高总和，仍需防护 |
| 早锁 | R015 早定之约 + R016 独掷者 | 第一掷提前承诺，最后只改一枚 | 早锁收益换取后续适应能力；解锁不会保留早锁奖励 |
| 末掷豪赌 | R017 放手一搏 + R021 玻璃誓约 | 第三掷放弃全部已知结果 | 最终全重掷 +3，但落败额外 +2 伤害 |
| 逆点防护 | R007 反向赌局 + R012 微光筹码 + R018 低潮护符 | 追低点；原本差骰变为优势 | 敌人也追低；最低 0 限制减分，不能无限向负分成长 |
| 单骰收尾 | R008 单骰决胜 + R006 庄家通吃 + R024 双响余威 | 优先保证最高骰，再兼顾平局与对子 | 加分牌停用；最高相同需比较总和，不能只留一颗 6 后放弃其余 |

### 可手算例子

**对子：** 玩家 4、4、2，敌人总和 12；双生骰使玩家 10 + 3 = 13，领先 1；双响余威再加 2，造成 3 伤害。没有三同号，不触发三重奏。

**逆点：** 玩家 1、2、3，敌人 2、3、4；微光筹码给 2 优势，玩家从 6 减到 4，敌人 9，造成 5 伤害。原始骰面仍然是 1、2、3。

**早锁：** 第一掷锁住两枚，第二掷后保持，第三掷重掷剩下一枚：早定之约 +2，独掷者 +2。若第二掷解锁再锁回，解锁的骰子不再贡献早定之约。

**单骰与镜面：** 玩家 6、5、4，敌人可见 1、2、3；镜面计分副本变为 6、2、3。最高都为 6，改比 15 与 11，造成基础 4 伤害。计分卡停用，但伤害卡仍可追加。

**玻璃与护符：** 玩家原始总和 3，玻璃提供 4 优势，敌人总和 8，落败差 1。差一点先免基础 1，玻璃风险加 2；若持有低潮护符，再减 2，最终 0 伤害。该回合仍是落败，可计入败中求变。

## 地图与敌人

首章八层：入门战 → 祭坛分支 → 战斗/事件 → 酒馆/商店/祭坛 → 精英/战斗 → 祭坛/事件/酒馆 → 酒馆/商店 → 首领。图中的每个分支都能通向终点。

锁匠与债主本版仅生命和金币不同，共用 AI；未实现能量税，也不在说明中冒充不同机制。镜面提供确定的对手反应。概率修士以半血偶数共鸣改变压力；首章改为三骰、36 生命、每偶数 1 优势，避免单靠第四骰压制普通构筑。

## 这轮模拟实际解决了什么

先以旧首领参数测试，发现普通奇数/对子/顺子成型构筑很难跨过四骰加成，而单骰全额加分又几乎不受伤。调整后，最终版本的 7,000 场独立战斗没有达到 40 回合保护上限。详见 [基线](balance-baseline.md)。

这仍**没有**证明各流派平衡：固定预组顺子在 Boss 对局为 84/200，逆点为 200/200；预组牌数、锁骰策略、起始生命与获得成本都不同。不能用此直接推导真实玩家通关率。逆点、险境的收益较强，顺子与单骰的平均战斗时间偏长，都是下一轮全路线试玩的重点。

禁止因为一份自动表漂亮就提高所有敌人生命；应优先看决策次数、失败能否归因、核心卡出现前能否活下来、以及未成型构筑是否有替代路线。

## 实现范围与后续门槛

**已实现：** 24 卡、槽位替换、图鉴筛选、条件奖励、纯结算、最后一掷预览、带种子随机序列、地图存档、结算诊断 JSON、自动测试与 CI。

**仅设计稿：** R025 临时骰面修正，R026 跨回合护盾，R027 邻位联动，R028 借贷，R029 敌人锁定干预，R030 商店折扣，R031 永久换面，R032 精确斩杀回复。

它们开放前须分别证明：骰面临时/永久状态不混淆；跨回合效果有单一消费时点；邻位不递归；借贷有到期账本；敌方干预在投掷前显示；商店价格与扣款同源；回复不能通过无伤拖局刷取。

后续测试先做完整路线和人工试玩，再决定是否增加敌人意图、规则槽重排、速度设置与更多骰种。本版不急于追加完整第二章。
